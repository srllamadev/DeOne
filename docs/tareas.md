# Tareas de DeOne · 5 integrantes · 12 horas

Reemplacen «Integrante 1–5» con los nombres del equipo. **H3** significa tres horas desde el inicio del hackathon. Cada fila tiene un entregable que se puede comprobar. Al terminar una tarea, añadan al final de su descripción el enlace al PR, la captura, el resultado de prueba o el hash correspondiente.

La base ya permite recorrer una remesa simulada. El trabajo parte de los módulos existentes y lleva la demo a Stellar Testnet. Consulten el [tablero por módulos](modulos.md) para las ramas y la [guía visual](estilos.md) para los estilos.
